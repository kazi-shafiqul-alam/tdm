What is verified now

The live atlas is a NASA/JPL Mars Trek WMTS client using three documented global Mars visualization layers. Coordinate selection, local persistence, Mars-sphere great-circle measurement and handoff to MarsWalk are implemented. MarsWalk runs a real graph-search calculation over its embedded grid, including multiple destinations and a point-by-point return-budget constraint; the current grid inputs, however, are synthetic demonstration values, not co-registered HiRISE/THEMIS/CRISM measurements.

Mars Trek coordinate→preserved input→local EQC mapping→synthetic demo cell→Dijkstra route→walkback check→traceable demo report

Confirmed issues corrected

  1. Jezero reference. The atlas center marker now uses the USGS Gazetteer center 18.41°N, 77.69°E; the reference rim uses the 47.52 km Gazetteer diameter.
  2. Neretva Vallis. The previous 76.83°E longitude is corrected to the USGS center 18.55°N, 77.20°E.
  3. Safety language. “Safest” and human-safe statements are replaced with “lowest modeled terrain cost,” “return-budget constraint,” and simulation language.
  4. Map-to-grid substitution. Imported coordinates remain visible alongside the synthetic cell, including any nearest-cell snap and model-plane offset.
  5. Missing terrain values. Missing elevation, p90 slope, sand or terrain-cost values exclude a cell instead of becoming favorable defaults. Missing science remains unknown.
  6. Export CRS. The atlas now exports a Mars-specific JSON schema instead of Earth/WGS84-style GeoJSON.
  7. Resource semantics. “Suit air” is now a demonstration EVA time/resource budget, not a physical oxygen model.
  8. Rover overlay. It is explicitly illustrative, not a spatially verified Perseverance traverse.

Spatial alignment + resolution

The atlas uses the Mars Trek EQ WMTS service and its documented global equirectangular Mars CRS. Great-circle measurement uses a 3,396,190 m Mars sphere and is explicitly not terrain-following distance. The MarsWalk grid declares a local equirectangular model with the same radius, latitude of true scale 18.4°, central longitude 77.5°, and 100 m cells. Importing a coordinate maps it mathematically into that model, but that does not establish scientific co-registration because the values are synthetic.

MarsWalk calculation audit

Routing: eight-neighbor graph with diagonal corner-cutting blocked; Dijkstra route legs; direction-aware elevation grade; demo sand slowdown; terrain-cost and bounded science terms.

Return check: a reverse Dijkstra map provides modeled walkback time. Every route point must satisfy elapsed + walkback + reserve ≤ budget.

Not validated: walking-speed constants, hazard thresholds, synthetic terrain/science values and resource budget are not human-Mars EVA standards. Dynamic illumination, communications, verified radiation planning, suit thermal limits and many human factors remain outside this build.

Environmental information

Air temperature remains “Unknown — MEDA archive replay not loaded,” and radiation remains “Unknown at Jezero.” A verified MEDA archive exists, but no specific sol is loaded. No Gale RAD value is presented as a Jezero measurement.

Scientific field notes

Jezero, Gale, Olympus Mons and Valles Marineris retain numbered citations and reference lists. Representative NASA/PDS/USGS sources and DOI records across all four notes were independently retrieved during this audit; no citation was invented to fill a gap. The local automated runner has no outbound DNS, so perpetual availability of every external URL is not claimed.
