DATA / 02

The MarsWalk terrain pipeline

01Official CTX DTM

Open the Mars 2020 Jezero elevation GeoTIFF from USGS/PDS or from a local copy.

0220 m working surface

Reproject the DEM into the local Jezero planning coordinate system used by MarsWalk.

03100 m cells

Summarize elevation coverage, p90 slope, steep fraction, and local elevation relief.

04Passability

Require at least 80% valid elevation coverage and a cell p90 slope no greater than 25°.

05Terrain cost

Blend normalized p90 slope (80%) with normalized within-cell relief (20%) for a transparent planning score.

06Route + walkback

Route through neighboring passable cells and verify the configured oxygen reserve can still cover the fastest modeled path home.

DATA / 04

Life-support disclosure

MarsWalk’s oxygen numbers are planning assumptions, not NASA flight rules, medical guidance, or a validated PLSS model. The interface exposes capacity, reserve, walking consumption, dwell consumption, dwell duration, and base pace so a judge can see and change every assumption.

The walkback test is structural: at each sampled route cell, oxygen already used + oxygen needed for the fastest modeled return + reserve must not exceed capacity.
