01 / MISSION BRIEF

The first Mars explorers will not need another pretty map.

They will need a map that explains where they can go, what the ground costs, what is worth seeing, and whether they can still get home.

THE CHALLENGE

Build a layered Martian route-planning experience that makes NASA data useful for a human explorer: terrain for movement, science context for purpose, and a return reserve that stays visible throughout the walk.

02 / FROM MAP TO ROUTE

How MarsWalk turns a real place into a route.

The map is not decoration. MarsWalk separates visual context from numerical terrain, then turns the terrain into route choices that can be checked against a return reserve.

01 · ORBITAL CONTEXT / JEZERO
WESTERN DELTA CRATER FLOOR CRATER RIM MARSWALK STUDY ZONE

See the place before calculating the walk.

The orbital layer gives geographic context: delta, crater floor, rim, and the focused Jezero study zone. It tells the explorer where the route is happening without pretending image color is a terrain measurement.

02
MEASURE THE GROUND

Convert the CTX elevation model into 100 m planning cells.

Each cell summarizes elevation, slope, local relief, passability, and modeled walking cost from the numerical terrain source.

03
COMPARE ROUTES

Run the same destinations through four route objectives.

Fast minimizes travel time. Safe penalizes difficult terrain more strongly. Balanced mixes both. Science adds documented mission-interest context.

04
CHECK THE RETURN

Keep the way home visible at every point.

The planner checks oxygen already used, the fastest modeled return to base, and the configured reserve against total capacity along the complete route.

06 / TRANSPARENCY

Real data where we have it.
Assumptions where we do not.

Terrain metrics are intended to come from the USGS/NASA MRO CTX DEM. NASA Trek imagery is visual context. Oxygen and suited-walking parameters are adjustable planning assumptions, not flight rules. Science “interest” in this build is contextual—not a claim of measured CRISM abundance unless a verified CRISM layer is added.
